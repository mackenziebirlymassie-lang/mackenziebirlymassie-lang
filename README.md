## What I Build

I like taking ambitious or weird ideas—a simulated OS in the browser, a terminal recorder, a desktop telemetry cockpit—and building them out just to see how far I can push them.

### CLI & Developer Tooling
| Project | Stack | What It Is |
| :--- | :--- | :--- |
| [**streamforge-CLI**](https://github.com/mackenziebirlymassie-lang/streamforge-CLI) | `JavaScript` | Automated CLI workflow tool built for fast, repeatable pipelines. |
| [**TermIRec**](https://github.com/mackenziebirlymassie-lang/TermIRec) | `TypeScript` | Terminal session recording and playback utility. |
| [**Replay-Bug**](https://github.com/mackenziebirlymassie-lang/Replay-Bug) | `TypeScript` | Tooling for capturing and replaying reproducible bug states. |
| [**GitStory**](https://github.com/mackenziebirlymassie-lang/GitStory) | `TypeScript` | *"A fun little project made out of boredom, cause why not"* — interactive Git history storytelling. |

### Systems, Dashboards & Web Apps
| Project | Stack | What It Is |
| :--- | :--- | :--- |
